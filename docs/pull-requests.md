# Opening a pull request

Keep a pull request to one change. Say what changed and why in the description; the template asks for both.

## Before you ask for a review

- Run `yarn lint` and `yarn test`.
- If you changed a module, run its integration tests: `yarn test:integration:modules`.

## Reviews

Every pull request needs one approval. Changes to payments and sign-in go to the people named in [CODEOWNERS](../CODEOWNERS).
